# visualfind-ai
Semantic image search using vision-language models

VisualFind AI is a computer vision project that aims to retrieve relevant images from natural-language queries using pretrained vision-language models.

PROJECT GOAL

A tool that lets users find images by describing what they're looking for instead of searching by filename.
For example, if someone searches for "a dog playing on grass", the tool should return images that match the description as closely as possible.
